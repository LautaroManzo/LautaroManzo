## Sobre mí

Desarrollador .NET, trabajando desde 2022 con C#, ASP.NET y Entity Framework sobre Oracle y SQL Server.

Por fuera del trabajo construyo proyectos propios para aprender tecnologías nuevas: React, Next.js, integración con IA y automatización de flujos.
